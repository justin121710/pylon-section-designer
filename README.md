# RC 斷面設計工具

單一 HTML 檔（`index.html`），零打包、零後端。頂列分頁切換兩個模組：

| 模組 | 內容 |
|---|---|
| **橋塔／柱斷面** | P-M 互制曲線、雙軸、Mander 圍束核心、容量設計剪力、扭矩、圍束筋 A_sh |
| **梁斷面**（RC，第一階段） | 矩形／T 型撓曲、正負彎矩切換、雙筋、剪力扭矩、耐震特殊抗彎構材、裂縫控制、撓度、建議配筋 |

兩個模組共用同一套排版基礎建設（CAD 標註、上下標、整數刻度、KaTeX 報告、列印 CSS）。

## 依據規範

混凝土結構設計規範（土木 401） + 公路橋梁耐震設計規範。全程 **kgf-cm 制**。

| 係數 | 值 | 出處 |
|---|---|---|
| φ_c 壓力控制（橫箍柱） | 0.65 | 土木401 |
| φ_t 拉力控制 | 0.90 | 土木401 |
| φ_v 剪力與扭矩 | 0.75 | 土木401 |
| 軸力截斷 | 0.80 P_o | 橫箍柱 |
| φ 過渡 | φ_c + (φ_t−φ_c)(ε_t−ε_ty)/(0.005−ε_ty) | ε_ty = f_y/E_s |

> **不可混搭**：φ_v = 0.75 係搭配 ACI 型 `Vc = 0.53√f'c·bw·d`。AASHTO 的
> φ_v = 0.90 是為 MCFT 校準的，套在此處會偷掉 20% 剪力裕度。

## 斷面範本

內建四組，涵蓋一般橋墩柱到長跨徑橋塔（A_g 相差 20 倍以上）：

| 範本 | 斷面 | f'c | 主筋 | ρ_g |
|---|---|---|---|---|
| 一般橋墩柱 | 實心 100×100 | 280 | #8 ×20 | 1.01% |
| 橋墩 | 實心 200×300 | 280 | #11 ×60 | 1.01% |
| 中跨徑橋塔 | 中空箱型 300×400×40 | 350 | #8 ×160 | 1.63% |
| 長跨徑橋塔 | 中空箱型 600×800×90 | 420 | #11 ×328 | 1.50% |

鋼筋號數：主筋 #4~#11、#14、#18（D13~D57）；箍筋／繫筋 #3~#7（D10~D22），
依 CNS 560。

## 功能

- **P-M 互制**：等效應力塊 + 離散鋼筋層，`a = min(β₁c, D)` 硬夾制，純壓／純拉點硬接。
  中空箱型受壓面積以受壓塊∩中空區的交集扣除，自動涵蓋 `a ≤ t_w`、`t_w < a < D−t_w`、
  `a ≥ D−t_w` 三段。
- **雙軸**：X/Y 兩條單軸曲線；`Pu ≥ 0.1f'c·Ag` 用 Bresler 倒數式，低軸壓自動切 PCA 載重輪廓法。
- **D/C**：定偏心射線法（`M_u → 0` 時退化為 `P_u/φP_n,max`）。
- **Mander 圍束核心**：由實際 A_sh 反算 k_e、f'_l → f'_cc、ε_cu,c，扣保護層後**真纖維積分**
  （非等效應力塊）畫出第二條曲線。
- **容量設計剪力**：`V_e = φ_o·M_n(at P_u)/L_v`，設計剪力取 `max(V_e, V_u)`；
  塑鉸區 `N_u < 0.1f'c·A_g` 時 `V_c = 0`；軸拉時分母改 35 並夾至 ≥ 0。
- **扭矩**：箱型封閉薄壁空間桁架，`A_t/s`、追加縱筋 `A_l`，中空斷面上限採**直接相加**。
- **圍束筋 A_sh**：中空箱型拆為四片獨立牆片逐片檢核（規範原文只寫給實心柱）。
- **繫筋**：每隔一根縱筋須側向支撐，且距被支撐筋淨距 ≤ 15 cm；淨距超過 15 cm 則每根都要。
  另查耐震 `h_x ≤ 35 cm`。可切換為「每一根主筋皆設」以觀察對 A_sh 的效果。
- **斷面圖標註**：CAD 式線性標註 —— 尺寸界線（起點留間隙、末端超出尺寸線）、尺寸線、
  實心箭頭、文字一律置於斷面輪廓外。量測距離不足以容納箭頭時自動改為「箭頭外置 + 引線」
  （仿 AutoCAD DIMFIT）。主筋淨距以琥珀色標示，不足時轉紅並附需求值與 ✗。
- **P-M 圖座標軸**：刻度步距限定為 1／2／2.5／5 × 10^k，格線落在 5,000、12,000
  這類整數上；軸界外推到步距的整數倍，首末格線貼齊圖框，且 P = 0 必為刻度。
- **輸入介面（方向 ④：工程表 ＋ 就地說明）**：三欄 —— 左側導軌（六組參數，帶 ✓/⚠/✗ 狀態，
  可篩選或看全部）、中間密集參數表（代號｜參數｜值｜單位｜狀態，分組標頭 sticky）、
  其下釘住「選取的參數」說明卡（影響什麼 / 規範限制 / 警示）。
  實作上是把原有的 `<input>`/`<select>` **搬移**進新版面，不重建 —— 所有 id、options、
  預設值與事件監聽原封不動，`compute()` / `computeBeam()` 一行未改。
  新增參數只需在 `PIN_META` 加一列；檢核結果經 `pinMapPylon()` / `pinMapBeam()` 映射為狀態徽章。
- **上下標排版**：介面與報告不出現 `M_ux`、`t_w` 這類底線寫法，全部渲染為真正的上下標。
  程式內部字串一律以 `X_ab` / `X^ab`（多字元用 `X_{ab}`）書寫，輸出前由 `SB()` 轉為
  HTML `<sub>`/`<sup>`（會跳過 `\( … \)` 的 KaTeX 原始碼），SVG 則由 `svgTxt()` 以
  `tspan` 的 `dy` 位移實作並逐段扣回基線。**新增文字時沿用此寫法即可，勿手寫標籤。**
- **多組載重**：可貼 CSV 批次匯入，自動找控制組合。
- **報告**：`window.print()` → 另存 PDF。KaTeX **display 模式**排版（`fleqn` 左對齊），
  所有方程式共用同一基準字級、分式維持全尺寸，不因擠在一行而縮小。每條公式
  **公式 → 代入 → 化簡 → 單位**四層全展開；關鍵斷點明細刻意包含 `a = t_w`
  幾何切換點，供人工複核。A4 直式 9 頁，無單頁溢出。
- **內部自測**：12 項一致性檢查（`c→∞` 收斂 P_o、`c→0` 收斂純拉、a 夾制、平衡點解析解、
  箱型分段積分連續性與斜率轉折、φ 值域、D/C 定偏心自洽、包絡線星形性）。

## 兩個需要使用者判斷的開關

1. **A_sh 之 b_c 配對**（④ 橫向鋼筋卡片內）。規範條文對 `b_c` 方向的敘述有歧義：
   - `垂直`（預設）：b_c 取與該組 A_sh 肢**垂直**的核心尺寸，即這些肢分布的跨距。
     使 `A_sh/(s·b_c)` 具有圍束壓力比的物理意義。
   - `平行`：b_c 取與該組肢**平行**的核心尺寸（「量至該組肢外緣」的字面讀法）。

   兩種讀法對**箱型牆片**可差 7 倍以上（長 585 cm vs 厚 77.5 cm）。實心方形斷面
   兩向對稱，差異不顯現。**請對照手上的條文自行確認後再選。**
   k_e、ρ_s、f'_l 一律採物理配對，不受此開關影響。

2. **繫筋配置**：規範最低（每隔一根）／每一根。箱型斷面在塑鉸區常需後者才滿足 A_sh。

## 已知限制

1. **不計算細長效應／彎矩放大係數**。輸入之 P_u、M_u 必須來自已含 P-Δ 的大變形幾何
   非線性分析；餵一階分析結果會高估容量。
2. 塑性形心僅對**對稱配筋**成立。
3. 不做彎矩-曲率 / 塑鉸轉角容量（pushover 範疇）。
4. **需連網**：Tailwind 與 KaTeX 走 CDN。斷網時版面會降級（有內嵌保底 CSS），
   但數學公式不會排版。
5. 實心斷面的繫筋以貫穿全斷面建模，超寬斷面實務上需改用內部套疊箍筋。

## 部署

推到 GitHub repo，Settings → Pages → 由主分支根目錄發布即可。無需 build step。

## 驗證

工具內建的自測只驗**內部一致性**，抓不到系統性的公式錯誤。若要真正驗證，請用報告 PDF
逐式手算複核；或提供一組已知答案的斷面（spColumn / SAP2000 Section Designer 輸出），
可再接成回歸測試。

# 梁斷面模組（RC・第一階段）

## 範本

| 範本 | 斷面 | f'_c | 配筋 | 耐震 |
|---|---|---|---|---|
| 橋面板 T 梁（內梁） | T 45×110、h_f 22、L 1500 | 280 | 底 8-#9（2 排）／頂 5-#7 | 否 |
| 蓋梁（矩形・耐震） | 150×180、l_n 850 | 280 | 底 12-#11／頂 16-#11 | 是 |
| 地梁（矩形） | 60×90 | 280 | 底 5-#8／頂 5-#7 | 否 |

## 計算內容

- **撓曲**：以二分法解 `ΣF = 0` 求中性軸（梁軸力為零），非查表或單筋近似。
  壓力筋自動處理 `f'_s < f_y` 並扣除佔位混凝土 `0.85f'_c`。
- **T 型分段**：`a ≤ h_f` 時 `A_c = b_e·a`；`a > h_f` 時 `A_c = b_e·h_f + b_w(a−h_f)`。
  有效翼緣寬 `b_e = min(L/4, b_w+16h_f, 梁中心距)`（邊梁另一組）。
- **正／負彎矩切換**：同一斷面兩種受力狀態。負彎矩時翼緣受拉不計入受壓區、斷面退化為
  `b_w×h` 矩形、拉力筋改取頂筋、建議配筋改搜頂筋。載重表同時帶 `M_u⁺` 與 `M_u⁻`。
- **鋼筋量限制**：`A_s,min = max(0.8√f'_c/f_y, 14/f_y)·b_w·d`；`ε_t ≥ 0.004`。
  該斷面 `M_u = 0` 時 A_s,min 不適用（簡支梁支承處），工具會改報 info 而非不合格。
- **剪力**：`V_c = 0.53√f'_c·b_w·d`（梁無軸壓增益項）、`V_s,max`、間距上限、`A_v,min`。
- **耐震特殊抗彎構材**（可切換）：容量設計剪力 `V_e = (M_pr⁺+M_pr⁻)/l_n + V_g`
  （`M_pr` 以 `1.25f_y`、`φ=1.0` 重解）；地震剪力佔比 ≥ 50% 時 `V_c = 0`；
  加密區 2h 且 `s ≤ min(d/4, 6d_b, 15cm)`；`b_w ≥ max(0.3h, 25)`；`l_n ≥ 4d`；`ρ ≤ 0.025`；
  接頭面 `φM_n⁺ ≥ 0.50 φM_n⁻`（正負兩向皆自動計算，不需另行輸入）。
- **扭矩**：實心斷面空間桁架，剪扭上限採**平方根合成**（箱型才是直接相加）。
- **裂縫控制**：`s ≤ min(38(2855/f_s) − 2.5c_c, 30(2855/f_s))`，`f_s = ⅔f_y`。
- **撓度**：`f_r = 2√f'_c` → `M_cr`；轉換斷面解彈性中性軸得 `I_cr`；Branson `I_e`；
  `Δ = K·M_a·L²/(E_c·I_e)`，K 由支承／載重型式選定（報告會列出 K 的推導）；
  長期 `λ_Δ = ξ/(1+50ρ')`。
- **建議配筋**：枚舉單一號數 × 根數，依淨距自動判斷排數（≤ 2 排）並**重算形心與 d**，
  篩選 `φM_n ≥ M_u`、`A_s ≥ A_s,min`、`ε_t ≥ 0.004`、淨距足夠者，依 A_s 由小到大列前 6 組。
- **內部自測**：軸力平衡殘差、單筋矩形梁對照解析解 `A_s f_y (d − a/2)`、
  T 梁 `a ≤ h_f` 等同 `b_e` 矩形、`a = h_f` 處面積連續與斜率由 `b_e` 轉 `b_w`、
  負彎矩退化為矩形、φ 值域、`I_cr < I_g`、`I_cr ≤ I_e ≤ I_g`、彈性中性軸落在斷面內、
  建議配筋全數滿足需求、`M_pr > M_n`。

## 梁模組已知限制

1. **不含預力**。PC 梁（有效預力、施工／使用階段應力、`f_ps`、隱裂縫彎矩）為第二階段。
2. 「任一斷面 `M_n ≥ 25%` 端部最大值」需整根梁的彎矩包絡線，單一斷面無法判斷。
3. 建議配筋限單一號數、最多 2 排，不混用號數。
4. T 梁扭矩的 `A_cp` 保守僅取腹板，未依 ACI 22.7.6.2 納入部分翼緣。
