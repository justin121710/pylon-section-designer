# RC 斷面設計工具

單一 HTML 檔（`index.html`），零打包、零後端。適用一般建築、地下結構（如滯洪池）與橋梁的 RC 柱、梁、版。
頂列分頁切換兩個模組：

| 模組 | 內容 |
|---|---|
| **柱斷面** | 矩形、中空箱型、**圓形（螺箍／圓箍）**；P-M 互制、雙軸、Mander 圍束核心、容量設計剪力、扭矩、圍束筋 A_sh／ρ_s |
| **梁／版斷面** | 矩形／T 型梁、**單位寬版**；撓曲、正負彎矩、雙筋、剪力扭矩、耐震特殊抗彎構材、裂縫控制、撓度、建議配筋 |

兩個模組共用同一套排版基礎建設（CAD 標註、上下標、整數刻度、KaTeX 報告、列印 CSS）。

## 設計依據（頂列切換）

| 設定 | 選項 | 影響 |
|---|---|---|
| 設計依據 | **建築物**：土木401 ＋ 建築物耐震設計規範 | 柱端加密區：V_e = 2M_pr/l_u（1.25f_y、φ=1）、V_c 歸零門檻 A_g f'c/20、間距 min(b/4, 6d_b, s_o)、A_sh 第三式（高軸力） |
| | **橋梁**：土木401 斷面強度與彎矩 φ ＋ 公路橋梁耐震設計規範 | 最大可能彎矩 1.3M_n；單柱 V_e = φ_o M_n/L_v（L_v＝柱高含帽梁）、構架式 2φ_o M_n/l_u（§4.2）；剪力 φ = 0.85、塑鉸區 V_c = 0.53(0.33+F)√f'c·A_e、非塑鉸區 0.53(1+F)√f'c·A_e、V_s ≤ 2.12√f'c·A_e（§5.3.3）；圍束筋式 5-5～5-8（§5.3.4）；間距 min(b/4, 6d_b, 15)；f'c 210～420、主筋 SD420W／SD280W（§5.2） |

## 功能

- **P-M 互制**：等效應力塊 + 離散鋼筋層，`a = min(β₁c, D)` 硬夾制，純壓／純拉點硬接。
  中空箱型受壓面積以受壓塊∩中空區的交集扣除，自動涵蓋 `a ≤ t_w`、`t_w < a < D−t_w`、
  `a ≥ D−t_w` 三段。
- **雙軸**：X/Y 兩條單軸曲線；`Pu ≥ 0.1f'c·Ag` 用 Bresler 倒數式，低軸壓自動切 PCA 載重輪廓法。
- **D/C**：定偏心射線法（`M_u → 0` 時退化為 `P_u/φP_n,max`）。
- **Mander 圍束核心**：由實際 A_sh 反算 k_e、f'_l → f'_cc、ε_cu,c，扣保護層後**真纖維積分**
  （非等效應力塊）畫出第二條曲線。Mander 模型之初始切線模數取 15,000√f'c（模型參數）；規範分析用 E_c 為 12,000√f'c（§19.2.2.1(b)，用於撓度與開裂斷面）。
- **容量設計剪力**：建築 `V_e = 2M_pr/l_u`；橋梁單柱 `V_e = φ_o·M_n,max/L_v`（L_v＝柱高含帽梁）、構架式（兩端塑鉸）`V_e = 2φ_o·M_n,max/l_u`，
  φ_o = 1.3（公路橋梁耐震設計規範 §4.2）；`M_n,max` 取各載重組合軸力下 `M_n` 的最大者；設計剪力取 `max(V_e, V_u)`。
- **橋梁剪力**（公路橋梁耐震設計規範 §5.3.3）：φ = 0.85（參數「φ 橋梁剪力」）；`A_e = 0.8A_g`，`F = N/(140A_g)`（壓）、`N/(35A_g)`（拉）；
  塑鉸區 `V_c = 0.53(0.33 + F)√f'c·A_e ≥ 0`、非塑鉸區 `0.53(1 + F)√f'c·A_e ≥ 0`；`V_s = A_sh f_yh d/a`，圓柱 `(π/2)A_h f_yh D/a`；`V_s ≤ 2.12√f'c·A_e`。扭矩仍依土木401。
- **橋梁圍束筋**（§5.3.4，只在塑鉸區）：矩形 `A_sh ≥ max{0.30·a·h_c(f'c/f_yh)(A_g/A_c − 1), 0.12·a·h_c(f'c/f_yh)(0.5 + 1.25P_e/f'cA_g)}`，
  h_c 量至外側箍筋中心；圓柱 `ρ_s ≥ max{0.45(A_g/A_c − 1)f'c/f_yh, 0.12(f'c/f_yh)(0.5 + 1.25P_e/f'cA_g)}`；圍束筋 f_yt 不得大於主筋 f_y。
- **橋梁材料與形狀**（§5.2、§5.8）：f'c < 210 不合格、> 420 提醒；主筋須 SD420W／SD280W；柱淨高／斷面深度 < 2.5 應視為壁式橋墩（本工具未涵蓋）。
- **剪力逐組合檢核**：`V_c` 隨 `N_u` 改變，最大 `V_u` 的組合未必控制（低軸壓組合常因 `V_c = 0`
  需最多箍筋）。每組合各算一次，取強度需求 `(A_v/s)_tot` 最大者為控制組合；介面與報告皆列出逐組合明細。
- **扭矩**：箱型封閉薄壁空間桁架，`A_t/s`、追加縱筋 `A_l`，中空斷面上限採**直接相加**。
- **圍束筋 A_sh**：中空箱型拆為四片獨立牆片逐片檢核（規範原文只寫給實心柱）。
- **繫筋**：每隔一根縱筋須側向支撐，且距被支撐筋淨距 ≤ 15 cm；淨距超過 15 cm 則每根都要。
  另查耐震 `h_x ≤ 35 cm`。可切換為「每一根主筋皆設」以觀察對 A_sh 的效果。
  箱型未設內層主筋（單層）時，繫筋無處錨定，**不計也不畫穿越壁厚的繫筋**、剪力取 2 肢，
  A_sh 通常不足並警示改雙層。
- **輸入防呆**：數值欄空白或非數字時，計算改用預設值，但該欄標紅框並列入警示（附採用的預設值）；
  無載重組合時以零載重佔位並警示；斷面內放不下主筋（淨距為負）時判定顯示「放不下」而非負值。
- **斷面圖標註**：CAD 式線性標註 —— 尺寸界線（起點留間隙、末端超出尺寸線）、尺寸線、
  實心箭頭、文字一律置於斷面輪廓外。量測距離不足以容納箭頭時自動改為「箭頭外置 + 引線」
  （仿 AutoCAD DIMFIT）。主筋淨距以琥珀色標示，不足時轉紅並附需求值與 ✗。
- **P-M 圖座標軸**：刻度步距限定為 1／2／2.5／5 × 10^k，格線落在 5,000、12,000
  這類整數上；軸界外推到步距的整數倍，首末格線貼齊圖框，且 P = 0 必為刻度。
- **輸入介面（方向 ④：工程表 ＋ 就地說明）**：三欄 —— 左側導軌（六組參數，帶 ✓/⚠/✗ 狀態，
  可篩選或看全部）、中間密集參數表（代號｜參數｜值｜單位｜狀態，分組標頭 sticky）、
  其下釘住「選取的參數」說明卡（影響什麼 / 規範限制 / 警示）。
  實作上是把原有的 `<input>`/`<select>` **搬移**進新版面，不重建 —— 所有 id、options、
  預設值與事件監聽原封不動，`compute()` / `computeBeam()` 一行未改。
  新增參數只需在 `PIN_META` 加一列；檢核結果經 `pinMapPylon()` / `pinMapBeam()` 映射為狀態徽章。
- **上下標排版**：介面與報告不出現 `M_ux`、`t_w` 這類底線寫法，全部渲染為真正的上下標。
  程式內部字串一律以 `X_ab` / `X^ab`（多字元用 `X_{ab}`）書寫，輸出前由 `SB()` 轉為
  HTML `<sub>`/`<sup>`（會跳過 `\( … \)` 的 KaTeX 原始碼），SVG 則由 `svgTxt()` 以
  `tspan` 的 `dy` 位移實作並逐段扣回基線。**新增文字時沿用此寫法即可，勿手寫標籤。**
- **多組載重**：柱、梁／版皆可貼 CSV 批次匯入（柱 `名稱,Pu,Mux,Muy,Vux,Vuy,Tu`；梁 `名稱,Mu+,Mu-,Vu,Tu`），自動找控制組合。
  逗號或 Tab 分隔（含 Tab 時數字可帶千分位逗號，可直接從 Excel 複製）；標題列、欄位不足或數值非數字的行略過並列出行號。
  已有組合時詢問「取代全部／附加在後面」。
- **判定列**：頂列下方一排膠囊顯示撓曲 D/C、剪力、箍筋、ρ_g、淨距（梁：裂縫、撓度）與警示數，
  點擊會切到該卡片所在的結果分頁並捲到它。參數狀態分四級：✓ 通過、<i>i</i> 需你確認（假設／配對等，非錯誤）、! 注意、✗ 不符。
  參數表只在「有檢核且通過」或有例外時標記；沒有檢核的列狀態欄留白，讓例外一眼可見。
- **版面（2026-10 改版）**：頂列＝品名｜柱／梁分段切換｜文件動作（唯一的實心按鈕是「從圖說匯入」）；
  其下狀態列＝設計依據與環境（左）｜判定膠囊（右）。右欄改為分頁（斷面與 P-M／結果摘要／軸向配置／
  伸展長度／〔梁：載重組合〕／警示（帶件數）／自測），卡片全部留在 DOM、只用 `.ws[data-active]`
  切換顯示，計算書與 Excel 匯出照常讀取。「內部自測」會自動切到自測分頁。選中的分頁存在
  localStorage `rcsd.ws.wsP` / `rcsd.ws.wsB`。
- **案件存檔**：所有輸入、載重與檢視狀態自動存在本機瀏覽器（重新整理不會遺失）；
  「儲存案件」下載 `.json`，「開啟案件」讀回，可交人複核或當回歸測試資料。
  選擇斷面範本即回到範本預設值；輸入或載重已和上次套用的範本不同時，先詢問「先儲存再套用／直接套用／取消」。
  瀏覽器封鎖本機儲存（無痕模式、封鎖網站資料、空間已滿）時，頂列常駐「本機自動保存無法使用」提醒。
- **報告**：`window.print()` → 另存 PDF。KaTeX **display 模式**排版（`fleqn` 左對齊），
  所有方程式共用同一基準字級、分式維持全尺寸，不因擠在一行而縮小。每條公式
  **公式 → 代入 → 化簡 → 單位**四層全展開；關鍵斷點明細刻意包含 `a = t_w`
  幾何切換點，供人工複核。A4 直式 9 頁，無單頁溢出。
  列印時若 KaTeX 未載入（斷網或 CDN 被擋），先提醒公式將以原始碼印出，可選擇取消或仍要列印。
- **長細效應判定**（參數群組「長細效應」）：輸入側向位移支撐（無側向位移支撐＝有側移／有側向位移支撐＝無側移）、
  有效長度係數 k、端彎矩比 M_1/M_2（僅有側向位移支撐；採土木401-112 慣例：單曲率為負、雙曲率為正），l_u 沿用柱淨高。
  r：矩形 0.30 × 考量方向尺度、圓形 0.25D、箱型以全斷面 √(I_g/A_g)；X、Y 兩向取 kl_u/r 較大者。
  - **建築**（土木401-112 §6.2.5.1）：無側向位移支撐 kl_u/r ≤ 22；有側向位移支撐 kl_u/r ≤ 34 + 12(M_1/M_2) 且 ≤ 40；
    不可忽略時二階彎矩 ≤ 1.4 倍一階彎矩（§6.2.5.3）。第一次近似分析時 k 可取 1.0（解說 R6.2.5）。
  - **橋梁**（公路橋梁設計規範 §7.3.5.2）：無支撐 kl_u/r < 22；有支撐 kl_u/r < 34 − 12(M_1b/M_2b)（M_1b/M_2b 單曲度為正，
    工具由 M_1/M_2 自動換號；無 40 上限）；有支撐構材 k 除經分析外為 1.0；**kl_u/r > 100 判不合格**（須依 §7.3.5.1 二階分析）。

  **只判定可否忽略，不計算彎矩放大**。計算書、Excel 檢核表第四節與檢核彙總同步列出
  （彙總判定「二階」不計入總判定 FAIL）。範本 k 值僅為示意（建築柱 1.0、懸臂墩柱／橋塔 2.0）。
- **橋梁保護層**（公路橋梁設計規範 §7.1.5 表 7.2）：「保護層環境（橋梁）」選露置土中或大氣中（主筋 5.0／箍筋 4.0）、
  不曝露（4.0／2.5）或直接澆鑄且永久埋置於土中或水中（7.5）；箍筋保護層取 c_o、主筋取 c_o + d_t。僅橋梁設計依據檢核。
- **柱主筋比**：下限 1%；上限橋梁 4%（公路橋梁耐震設計規範 §5.3.1）、建築特殊抗彎矩構架柱 6%（土木401-112 §18.4.4.1）、
  其他柱 8%（§10.6.1.1），超過即不合格；超過 4% 另提醒施工性。
- **內部自測**：實心 12 項／圓形 13 項／箱型 14 項一致性檢查（圓形另驗半圓面積與形心解析解、剪力控制組合為最嚴者、`c→∞` 收斂 P_o、`c→0` 收斂純拉、a 夾制、平衡點解析解、
  箱型分段積分連續性與斜率轉折、φ 值域、D/C 定偏心自洽、包絡線星形性）。

## 沿構材軸向箍筋配置（立面圖）

柱與梁各有一張「箍筋配置（沿軸向立面）」：標出加密區／一般區／搭接區的範圍、間距、餘數格與數量（搭接區以底色標示，箍筋為實際位置），計算書與 Excel 同步附圖。

- **柱**：加密區長度 `l_o = max(h, l_u/6, 45 cm)`（土木401 §18.4.5.1；橋梁塑鉸區同式）。「塑鉸區位置」可選兩端（建築柱）或僅底端（懸臂墩柱、橋塔）。
  加密區外間距另算：V_c 不折減、設計剪力仍取 V_e，並受 A_v,min、規範上限、扭矩與橫箍通則控制；
  建築另加 `min(6d_b, 15 cm)`（§18.4.5.5）；橋梁採「不少於塑鉸區之 50%（s ≤ 2s₁）」，此為 AASHTO 耐震細則慣例、**非我國規範明列**。
  圓柱螺箍在加密區外仍需非耐震 ρ_s（0.45 式）。「塑鉸區／柱端加密區」設為「否」時，全長同一間距。
- **梁**：耐震梁自柱面 2h 內加密（§18.3.4.1），其外 V_c 不折減、`s ≤ d/2`（§18.3.4.6）；一般梁以最大剪力之間距配置全長（保守）。版不適用。
- **配置規則（施工性：間距一律採實務值，不均分成零碎間距）**：第一支距接頭面 `e = min(5 cm, ⌊s₁/2⌋)`（整數 cm）；
  加密區數量 `INT((l_o − e)/s₁) + 1`；中段以 s₂ 排列，**餘數置於中央一格**（≤ s₂）；餘數 < s₂/2 時與相鄰一格合併後拆成
  兩格（取整數 cm，如 20、20），避免出現極短的間隔。兩端加密區相接或中段不足一個 s₁ 時，全長以 s₁ 依同一規則排列。
  網頁 `fillPlan()` 與 Excel「gA～gI2」項目相同。
- **箍筋肢橫向間距**（沿斷面寬度）：≤ min(d, 60)，V_s > 1.06√f'c·b_w·d 時 ≤ min(d/2, 30)。梁依土木401-112 表 9.7.6.2.2 判定；
  柱僅為參考（ACI 318-19 表 10.7.6.5.2；土木401-112 柱之表 10.7.6.5.2 只列沿柱長間距，未列沿寬度），超過只提醒、不判不合格。
  矩形柱每根主筋皆設肢取主筋間距、每隔一根取 2 倍；耐震梁另以肢距估「受側撐主筋間距 ≤ 35 cm」（§18.3.4.2）。
  箱型柱內外層箍筋肢跨壁厚，厚壁時以柱條文檢核偏保守，**只警示不判 NG**。
- 範本隨之調整：建築 RC 方柱改「每一根主筋皆設」繫筋、蓋梁 6 肢、滯洪池頂版大梁 3 肢（原配置肢距超限）。

## 主筋伸展長度與搭接（土木401-112 第 25 章）

柱、梁各有一張「主筋伸展長度與搭接」表，計算書逐式代入，Excel 檢核表「八之二／五之二」節全部為公式。
公式與係數已逐條對照土木401-112 原文（kgf-cm 制）。

| 項目 | 公式（kgf-cm） | 條文 |
|---|---|---|
| 直線受拉 l_d | `f_y/(3.5λ√f'c) · ψ_tψ_eψ_s/((c_b+K_tr)/d_b) · d_b ≥ 30`，`(c_b+K_tr)/d_b ≤ 2.5`，`K_tr = 40A_tr/(s·n)`（**不含 ψ_g**） | §25.4.2.4、表 25.4.2.5 |
| 標準彎鉤 l_dh | `f_yψ_eψ_rψ_oψ_c/(23λ√f'c) · d_b^1.5 ≥ max(8d_b, 15)`；大於 D36 時 ψ_r = 1.6、ψ_o = 1.25 | §25.4.3.1、表 25.4.3.2 |
| 彎鉤前版式（可擇用） | `0.075ψ_e f_y d_b/√f'c`（輕質 ×1.3），f'c 上限 D25↓700／D29 490／D32 420／D36 350；可再乘表 25.4.3.8 之 0.7、0.8 | §25.4.3.5～25.4.3.8 |

| 受壓 l_dc | `max(0.075f_yψ_r/(λ√f'c), 0.0044f_yψ_r)·d_b ≥ 20`（螺箍或 D13 以上箍筋 @ ≤ 10 cm 時 ψ_r = 0.75） | §25.4.9 |
| 受拉搭接 | 甲級 `1.0ψ_g l_d`、乙級 `1.3ψ_g l_d`，≥ 30 cm；ψ_g = 1.0／1.08／1.15／1.30（f_y 4200／5000／5600／7000） | 表 25.5.2.1 |
| 受壓搭接 | f_y ≤ 4200：`0.0073f_y d_b`；≤ 5600：`(0.013f_y − 24)d_b`；以上另與乙級搭接取大；f'c < 210 加 1/3；≥ 30 | §25.5.5.1 |

- 自動判定：ψ_t（頂筋下方混凝土 > 30 cm 取 1.3）、ψ_e（環氧樹脂依保護層與淨距 1.5／1.2）、ψ_s（D19 以下 0.8）、λ、ψ_c（f'c < 420 時 f'c/1050 + 0.6）；√f'c 上限 26.5。
  f_y ≥ 5600 且主筋中心距 < 15 cm 時檢查 K_tr ≥ 0.5d_b（§25.4.2.2）。
- 使用者選擇（參數表「伸展長度」組）：環氧樹脂、λ、ψ_r／ψ_p、ψ_o、超量鋼筋折減 A_s,需求/A_s,使用。
  超量折減只用於直線 l_d 與受壓 l_dc，不用於彎鉤、擴頭、搭接及抵抗地震力系統（§25.4.10.2）。
- c_b、K_tr 依實際配筋自動計算：K_tr 以搭接所在之一般區箍筋間距計；矩形柱逐面取大，圓形與箱型 K_tr 保守取 0。
- **泥水中灌注**（參數表「伸展長度」組「混凝土澆置方式」，柱、梁皆有）：依建築物基礎構造設計規範 §7.6.2 第 2 款，
  混凝土剪力強度 V_c × 0.75（折減 25%），直線、彎鉤、擴頭、受壓伸展長度與搭接長度 × 1.3（增加 30%，先依第 25 章計算並取下限後再乘）；
  f'c < 210 kgf/cm² 判不合格。計算書與 Excel 各式均列出 ×0.75、×1.3。本文係對地下牆（連續壁）而言，場鑄樁可比照使用。
- 範本另增「建築 RC 大梁（耐震）」T 型 40×75 與「建築 RC 小梁（一般）」30×60。

## 剪力 V_c（土木401-112 表 22.5.5.1）

- **柱、配箍筋之梁**（箍筋間距恆受 A_v,min 控制，A_v ≥ A_v,min 成立）：式 (a)
  `V_c = [0.53λ√f'c + N_u/(6A_g)]·b_w·d`，`N_u/(6A_g) ≤ 0.05f'c`、`V_c ≤ 1.33λ√f'c·b_w·d`、`V_c ≥ 0`（軸拉 N_u 為負）。
  取代舊版 ACI 318-14 形式 `0.53(1 + N_u/140A_g)√f'c·b_w·d`。
- **版（不配剪力筋，A_v < A_v,min）**：式 (c) `V_c = 2.12λ_sλ(ρ_w)^{1/3}√f'c·b_w·d`，`λ_s = √(2/(1 + d/25)) ≤ 1`（§22.5.5.1.3），√f'c ≤ 26.5。
  舊版未計尺寸效應，厚版偏不保守（60 cm 版 λ_s ≈ 0.8）；滯洪池頂版範本因此加厚至 80 cm、配 #8@10，側牆範本的 V_u 依三角形土壓 V = 3M/H 更正為 17.5 tf/m。
- 耐震加密區（塑鉸區）V_c 歸零條件不變；λ 與伸展長度共用「混凝土單位重」設定。

- 匯出模組以 `fetch(..., {cache:'no-cache'})` 載入，部署新版後不會用到瀏覽器快取的舊版。
- Excel 內**不含**：Mander 圍束曲線（參考資訊）、建議配筋清單；新增 Excel 2010 後之函數須以 `_xlfn.` 前綴寫入。

## 圓形柱

- 受壓區為圓形弓形：圓心角 θ = 2acos((R−a)/R)，A = R²(θ−sinθ)/2，形心 4R sin³(θ/2)/[3(θ−sinθ)]。
- 雙軸：圓形各向同性，以合彎矩 √(M_ux²+M_uy²) 對單一 P-M 曲線檢核。
- 螺箍：φ_c = 0.75、軸力截斷 0.85P_o、主筋 ≥ 6 根、淨距 2.5～7.5 cm；圓箍同橫箍柱（0.65／0.80）。
  實務間距表對螺箍另開放 6、5 cm（一般箍筋最小 7.5 cm）。
- 「從圖說匯入」可辨識圓柱（直徑 D、主筋總根數、螺箍／圓箍）。
  切換型式時 φ_c 與截斷值自動改為對應規範值（使用者自訂過的不覆蓋）。
- ρ_s = 4A_sp d_s/(D_c² s) ≥ max{0.45(A_g/A_ch−1)f'c/f_yt, 耐震 0.12f'c/f_yt, 建築高軸力 0.35k_f P_u/(f_yt A_ch)}。
- 剪力 b_w = D、d = 0.8D、A_v = 2A_sp；Mander 圓形 k_e（螺箍一次方、圓箍平方）。

## 單位寬版

- b = 100 cm，鋼筋以「號數 @ 間距」輸入（每公尺根數可為小數），不配箍筋。
- A_s,min = ρ_min·b·h（預設 0.0018；水工 0.003）、主筋間距 ≤ min(3h, 45 cm)、須 V_u ≤ φV_c；版不配剪力筋，V_c 取表 22.5.5.1 式 (c)（含尺寸效應 λ_s 與 ρ_w）。
- 受拉側無鋼筋（如負彎矩但未配頂筋）時 φM_n = 0、判定「無受拉鋼筋」，裂縫寬度顯示 ∞。
- 建議配筋列出各號數可用的最大間距。範本：滯洪池頂版、側牆、頂版大梁。
- 使用載重彎矩分正、負：正彎矩（跨中）M_D、M_L 用於撓度與裂縫寬度；支承負彎矩 M_D⁻、M_L⁻ 用於負彎矩斷面之裂縫寬度。
  撓度為跨度性質，**只在正彎矩斷面判定**；裂縫控制間距依受拉側（負彎矩取頂筋）。

## 兩個需要使用者判斷的開關

1. **A_sh 之 b_c 配對**（④ 橫向鋼筋卡片內）。
   - `垂直`（預設）：b_c 取與該組 A_sh 肢**垂直**的核心尺寸，即這些肢分布的跨距。
     土木401-112 解說 R18.4.5.4 明示「對每一方向而言，b_c 為垂直構成 A_sh 之箍筋肢之核心尺度」，即此讀法。
   - `平行`：b_c 取與該組肢**平行**的核心尺寸（字面另一讀法），**非規範讀法，僅供比較**；選用時參數表標示「非規範」。

   兩種讀法對**箱型牆片**可差 7 倍以上（長 585 cm vs 厚 77.5 cm）。實心方形斷面兩向對稱，差異不顯現。
   k_e、ρ_s、f'_l 一律採物理配對，不受此開關影響。

2. **繫筋配置**：規範最低（每隔一根）／每一根。箱型斷面在塑鉸區常需後者才滿足 A_sh。
   不規則配置可展開斷面圖上方「進階：自訂繫筋位置」改為 **自訂（於斷面圖點選）**：按「點選繫筋」，點外圍主筋（角隅除外）加設或取消繫筋；
   實心斷面繫筋貫穿斷面勾住兩對面主筋，箱型則為該位置兩側牆片各一支貫穿壁厚（須有內層主筋可勾；
   位於另一向牆片內之角隅區主筋視為由該牆片箍筋支撐）。編輯中以橘色虛圈標出未受側撐之主筋。
   A_sh、剪力肢數、h_x、肢距一律依實際點選位置計算，並檢核 §25.7.2.3（不得連續 2 根未撐、未撐筋淨距 ≤ 15 cm）
   與 §18.4.5.2(f)（高軸力時每根皆須側撐）。配置存在案件檔；主筋根數改變時以規範最低重新起始並提示。
   Excel 之「配筋座標」K、L 欄為點選旗標；繫筋根數、n_l、h_x 與肢距寫入匯出當下網頁值，檢核表與計算書開頭並加註警語
   （這幾格在 Excel 內修改主筋根數不會重算）。重疊閉合箍筋在 A_sh 與肢數上等同兩支繫筋，故不另提供。

1. **不計算彎矩放大係數**：長細效應只判定可否忽略（建築 §6.2.5.1、橋梁公路橋梁設計規範 §7.3.5.2）。不可忽略時，輸入之 P_u、M_u 必須來自

## 計算內容

- **撓曲**：以二分法解 `ΣF = 0` 求中性軸（梁軸力為零），非查表或單筋近似。
  壓力筋自動處理 `f'_s < f_y` 並扣除佔位混凝土 `0.85f'_c`。
- **T 型分段**：`a ≤ h_f` 時 `A_c = b_e·a`；`a > h_f` 時 `A_c = b_e·h_f + b_w(a−h_f)`。
  有效翼緣寬 `b_e = min(L/4, b_w+16h_f, 梁中心距)`（邊梁另一組）。
- **正／負彎矩切換**：同一斷面兩種受力狀態。負彎矩時翼緣受拉不計入受壓區、斷面退化為
  `b_w×h` 矩形、拉力筋改取頂筋、建議配筋改搜頂筋。載重表同時帶 `M_u⁺` 與 `M_u⁻`。
- **斷面圖**：受壓區 a 以淡色填滿，並以「● 起點（最外受壓纖維）→ ▶ 終點（受壓區邊界）」標示量測範圍。
  橫向鋼筋：外箍 2 肢（閉合，兩端 135° 於頂部角隅搭接）；肋筋為 ㄇ 形開口箍（頂部兩轉角包 2 根頂筋，
  底端兩支 135° 彎鉤向內勾 2 根第 1 排底筋）；繫筋勾上下各 1 根（底端 135°、頂端 90°，沿梁長交替）。
  - 依「箍筋肢數」自第 1 排底筋挑選肢位，每 2 肢一個肋筋、奇數多出 1 肢為置中繫筋，頂部轉角取最近的頂筋。
    先試平均挑選；若肢距超限或上下偏差 > d_b（頂、底筋根數不同時常見），自動窮舉內部肢位（組合數 ≤ 5000），
    取合格且盡量對稱者並提示「已自動調整肢位」；找不到合格者則維持平均挑選並警示。
  - 上下所勾主筋水平位置不同時肢畫成傾斜，偏差 > d_b 時警示建議調整主筋位置或肢數。
  - **外箍型式**：一體式閉合箍（兩端 135° 角隅搭接）或兩件式（§18.3.4.3：兩端 135° 之 U 形肋筋＋頂部繫筋封口，
    繫筋一端 135°、一端 90°，相鄰箍交替、單側樓板時 90° 端置樓板側）。不影響肢數與強度；矩形梁承受扭力時
    提醒 90° 端須受樓板束制（§25.7.1.6.1）。
- **箍筋肢橫向間距**以實際肢位計算（肢中心線：箍／肋筋在主筋外側 (d_b+d_t)/2，繫筋貼主筋側邊），
  於底筋與頂筋兩個高程各取相鄰兩肢最大距離，取大者；結果卡列出各肢位置。Excel 寫入匯出當下之網頁值。
- 橋墩帽梁範本（底筋 12、頂筋 16 根不對齊）採 8 肢（3 個肋筋），肢距 ≤ 30 cm 且上下偏差 ≤ d_b。
- **主筋淨距**（土木401 §25.2.1）：底筋第 1 排與頂筋（單排）皆檢核淨距 ≥ max(2.5 cm, d_b, 4/3·d_agg)；版以「間距 − d_b」計。
- **鋼筋量限制**：`A_s,min = max(0.8√f'_c/f_y, 14/f_y)·b_w·d`；`ε_t ≥ ε_ty + 0.003`（P_u < 0.1f'cA_g 之梁須拉力控制，土木401-112 §9.3.3.1；解說明言已取消舊版 0.004）。
  該斷面 `M_u = 0` 時 A_s,min 不適用（簡支梁支承處），工具會改報 info 而非不合格。
- **剪力**：`V_c = 0.53λ√f'_c·b_w·d`（表 22.5.5.1 式 (a)，梁 N_u = 0）、`V_s,max`、間距上限、`A_v,min`。
- **耐震特殊抗彎構材**（可切換）：容量設計剪力 `V_e = (M_pr⁺+M_pr⁻)/l_n + V_g`
  （`M_pr` 以 `1.25f_y`、`φ=1.0` 重解）；地震剪力佔比 ≥ 50% 時 `V_c = 0`；
  加密區 2h 且 `s ≤ min(d/4, 6d_b, 15cm)`；`b_w ≥ max(0.3h, 25)`；`l_n ≥ 4d`；`ρ ≤ 0.025`；
  接頭面 `φM_n⁺ ≥ 0.50 φM_n⁻`（正負兩向皆自動計算，不需另行輸入）。
- **扭矩**：實心斷面空間桁架，剪扭上限採**平方根合成**（箱型才是直接相加）。
- **裂縫控制**（土木401-112 表 24.3.2）：`s ≤ min(38(2800/f_s) − 2.5c_c, 30(2800/f_s))`，`f_s = ⅔f_y`（§24.3.2.1）。
- **撓度**：`f_r = 2√f'_c` → `M_cr`；`E_c = 12,000√f'_c`（§19.2.2.1(b)）；轉換斷面解彈性中性軸得 `I_cr`；`I_e` 依表 24.2.3.5（Bischoff 式：`M_a ≤ (2/3)M_cr` 時 `I_g`，否則 `I_cr/[1 − ((2/3)M_cr/M_a)²(1 − I_cr/I_g)]`）；
  `Δ = K·M_a·L²/(E_c·I_e)`，K 由支承／載重型式選定（報告會列出 K 的推導）；
  長期 `λ_Δ = ξ/(1+50ρ')`。
- **建議配筋**：枚舉單一號數 × 根數，依淨距自動判斷排數（≤ 2 排）並**重算形心與 d**，
  篩選 `φM_n ≥ M_u`、`A_s ≥ A_s,min`、`ε_t ≥ ε_ty + 0.003`、淨距足夠者，依 A_s 由小到大列前 6 組。
- **內部自測**：軸力平衡殘差、單筋矩形梁對照解析解 `A_s f_y (d − a/2)`、
  T 梁 `a ≤ h_f` 等同 `b_e` 矩形、`a = h_f` 處面積連續與斜率由 `b_e` 轉 `b_w`、
  負彎矩退化為矩形、φ 值域、`I_cr < I_g`、`I_cr ≤ I_e ≤ I_g`、彈性中性軸落在斷面內、
  建議配筋全數滿足需求、`M_pr > M_n`。
